    왜 'IMOE_ROUTINE'인가요?

    일반 할 일 · 메모 앱

    창을 닫으면 머릿속에서도 끝

    • • 앱을 일부러 열어야 오늘 루틴을 볼 수 있음
    • • 바쁜 업무·공부 중에는 존재를 잊기 쉬움
    • • 매일 체크를 손으로 다시 초기화해야 함
    기존 위젯 · 스티커 메모

    투박한 테두리가 배경을 가림

    • • 시커먼 네모 박스와 제목줄이 바탕화면을 망침
    • • 요일마다 일정을 일일이 새로 적거나 넘겨야 함
    • • 작은 위젯 창 안에서 편집하려면 답답함

    ✨ 배경을 해치지 않는 투명 글래스

    불필요한 테두리나 타이틀바 없이 상단 컬러 포인트 바만 남겼습니다. 검정/하얀 글씨 전환과 2%~95% 투명도로 어떤 배경화면에도 자연스럽게 녹아듭니다.

    📅 월~일 요일 자동 전환 & 리셋

    위젯 하나만 띄워두면 자정(00:00)이나 PC 절전 해제 시 자동으로 오늘 요일의 루틴으로 바뀌고 전날 체크 표시가 깔끔히 초기화됩니다.

    ☑️ 체크박스 ON / OFF 자유 전환

    하나씩 체크하며 성취감을 느끼고 싶을 땐 체크박스를 켜고, 단순히 오늘 할 일만 눈으로 확인하고 싶을 땐 꺼서 도트 리스트로 쓸 수 있습니다.

    📝 넉넉한 별도 루틴 편집 창

    위젯을 작게 줄여도 편하게 편집할 수 있도록 별도의 420×590 편집 창을 제공합니다. 평일 복사·매일 복사 버튼으로 반복 루틴도 1초 만에 채우세요.

    🔒 투명 라인 고정·잠금 & 트레이

    컬러풀한 이모지 대신 깔끔한 투명 라인 아이콘으로 항상 위·위치 잠금 상태를 표시합니다. 작업표시줄을 차지하지 않고 트레이에서 가볍게 관리됩니다.

    ⚡ 100% 오프라인 로컬 저장

    서버 전송이나 계정 로그인 없이 모든 루틴이 내 PC의 로컬 JSON(+직전 백업)에 안전하게 저장됩니다. 포터블·설치형 모두 시작 시 자동 실행을 지원합니다.

    자주 묻는 질문

    포터블 버전과 설치형 버전의 차이는 무엇인가요?

    포터블(.EXE)은 별도 설치 과정 없이 단일 파일로 바로 실행되며(실행 시 임시 폴더에 자동 전개), 설치형(Setup .EXE)은 고정 경로에 설치되어 더 빠른 실행 속도·시작 메뉴 등록·제어판 제거·윈도우 시작 시 자동 실행에 최적화되어 있습니다.

    루틴 데이터는 어디에 저장되나요?

    사용자 PC의 로컬 AppData(imoe-routine/routine-data.json)에 저장되며 원자적 쓰기와 직전 정상 백업(.bak.json) 자동 복구를 지원합니다. 외부 서버 전송은 0%입니다.

    요일이 바뀌면 체크 표시도 초기화되나요?

    네. 로컬 시간 자정(00:00)이 지나거나 절전 모드에서 복귀하면 자동으로 오늘 요일 루틴으로 전환되며 어제 체크했던 항목들이 새 하루에 맞게 초기화됩니다.

    정말 무료인가요? 문의처는 어디인가요?

    네, 광고·결제·기능 제한이 전혀 없는 100% 무료 앱입니다(IMOE 배포). 오류 제보 및 문의:

    무료 앱 안전성과 처음 실행 시 윈도우 보호 창(SmartScreen)이 뜨면?

    연간 유료 코드 서명 인증서 없이 가볍게 배포하는 100% 오프라인 무료 앱입니다. 첫 실행 시 파란 안내 창(Windows의 PC 보호)이 뜨면 [추가 정보] → [실행]을 한 번만 눌러주세요. 인터넷 통신이나 개인정보 수집은 전혀 없습니다.
